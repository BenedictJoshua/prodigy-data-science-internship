# Prodigy Data Science Internship

A consolidated portfolio of five data science projects completed during the Prodigy InfoTech Data Science Internship.

## Projects

| Task | Project | Key Technologies |
|---|---|---|
| 01 | Data Visualization | Python, Pandas, Matplotlib |
| 02 | Data Cleaning and EDA | Python, Pandas, Matplotlib, Seaborn |
| 03 | Decision Tree Classifier | Python, Pandas, Scikit-learn |
| 04 | Social Media Sentiment Analysis | Python, Pandas, Matplotlib, Seaborn |
| 05 | Traffic Accident Analysis | Python, Pandas, Matplotlib, Seaborn |
